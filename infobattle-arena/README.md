# 🎮 InfoBattle Arena

**Битва знаний по информатике в стиле RPG!**

## 📖 Описание

InfoBattle Arena - это образовательная игра, где дети сражаются с "боссами" по информатике, отвечая на вопросы. Игра вдохновлена платформой Wayground и включает:

- ⚔️ **Пошаговые битвы** с боссами через вопросы/ответы
- 🏆 **Таблицу лидеров** для соревнования между игроками
- 🌍 **Общий прогресс-бар сообщества** 
- 💫 **Красивые анимации** и прогресс-бары здоровья
- 📱 **Адаптивный веб-интерфейс** для детей

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- Windows Server (или любая ОС)
- Браузер (Chrome, Firefox, Edge)

### Установка

1. **Клонируйте репозиторий** или скопируйте файлы проекта

2. **Установите зависимости**:
```bash
cd infobattle-arena/backend
pip install -r requirements.txt
```

3. **Запустите сервер**:
```bash
python server.py
```

4. **Откройте в браузере**:
```
http://localhost:5000
```

Для доступа с других устройств в сети используйте IP вашего сервера:
```
http://YOUR_SERVER_IP:5000
```

## 🎯 Особенности игры

### Для игроков:
- Выбор из нескольких боссов разной сложности
- Анимированные прогресс-бары здоровья (игрок vs босс)
- Мгновенная обратная связь при ответах
- Таблица лидеров в реальном времени
- Общий прогресс всех игроков

### Для администраторов:
- Все данные хранятся локально на сервере
- Легко добавлять новые вопросы в `data/questions.json`
- WebSocket для синхронизации в реальном времени
- Автоматическое сохранение результатов

## 🎮 Как играть

1. Введите своё имя
2. Выберите босса для битвы
3. Отвечайте на вопросы по информатике:
   - ✅ Правильный ответ → босс получает урон
   - ❌ Неправильный ответ → вы получаете урон
4. Победите босса, чтобы попасть в таблицу лидеров!

## 🔧 Настройка

### Добавление новых вопросов

Откройте `data/questions.json` и добавьте нового босса:

```json
{
  "id": 3,
  "name": "Название босса",
  "description": "Описание",
  "health": 200,
  "questions": [
    {
      "question": "Ваш вопрос?",
      "options": ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
      "correct": 0,
      "damage": 50
    }
  ]
}
```

### Изменение порта

В `server.py` измените порт в последней строке:
```python
socketio.run(app, host='0.0.0.0', port=5000, debug=True)
```

## 🌐 Работа в сети

Для доступа с других устройств:

1. Откройте порт 5000 в брандмауэре Windows
2. Запустите сервер с внешним IP:
```python
socketio.run(app, host='0.0.0.0', port=5000)
```
3. Дети подключаются по: `http://YOUR_SERVER_IP:5000`
